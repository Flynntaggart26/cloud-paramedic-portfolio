# Sözlük

Sitedeki sözlükle aynı içerik. Terimler Türkçe açıklanır, İngilizce karşılığı korunur.

| Türkçe | İngilizce | Kısa anlam |
|---|---|---|
| Bulut bilişim | Cloud computing | İnternet üzerinden sunulan, ölçülen bilişim hizmeti |
| Bölge | Region | Bir veya daha fazla veri merkezini kapsayan coğrafi alan |
| Kullanılabilirlik bölgesi | Availability zone (AZ) | Bölge içinde izole edilmiş kaynak grubu |
| Uç nokta | Edge location | Kullanıcıya yakın önbellek ve dağıtım noktası |
| Gecikme | Latency | İstek ile yanıt arasında geçen süre |
| Çok kiracılılık | Multi-tenancy | Aynı altyapının mantıksal olarak ayrılmış müşterilere sunulması |
| Esneklik | Elasticity | Talebe göre otomatik kapasite artışı ve azalışı |
| Hizmet düzeyi anlaşması | SLA | Sağlayıcının taahhüt ettiği kullanılabilirlik ve tazminat |
| Kimlik ve erişim yönetimi | IAM | Kullanıcı ve rol bazlı yetkilendirme |
| Aktarımda şifreleme | Encryption in transit | Verinin ağ üzerinde TLS ile korunması |
| Durgun halde şifreleme | Encryption at rest | Disk veya nesne depolamada şifreleme |
| Kişisel sağlık verisi | PHI | Bir kişiyle ilişkilendirilebilen sağlık verisi |
| Kişisel veri | PII | Kimliği belirlenebilir kişiye ait veri |
| Yedekleme | Backup / snapshot | Geri dönüş için alınan veri kopyası |
| Kurtarma süresi hedefi | RTO | Kesintiden sonra azami kabul edilebilir süre |
| Kurtarma noktası hedefi | RPO | Kabul edilebilir azami veri kaybı |
| Satıcıya bağımlılık | Vendor lock-in | Sağlayıcı değiştirme maliyetinin yükselmesi |
| Bulut maliyet yönetimi | FinOps | Harcamayı görünür ve yönetilebilir kılma pratiği |
| Veri işleme sözleşmesi | BAA / DPA | Sağlık verisi (BAA) veya kişisel veri (DPA) için işleme sözleşmesi |

## Sık karıştırılan terimler

- **Region / Availability zone:** Bölge coğrafi alandır; kullanılabilirlik bölgesi o coğrafi alanın içindeki izole kaynak grubudur. Yedeklilik için ikinci AZ'ye, ikametgah için bölgeye bakılır.
- **Yedekleme / arşiv:** Yedek geri dönüş içindir, arşiv saklama içindir. İkisi farklı saklama ve erişim politikası gerektirir.
- **RTO / RPO:** RTO "ne kadar süre kapalı kalabiliriz", RPO "ne kadar veri kaybedebiliriz" sorusunun cevabıdır.
