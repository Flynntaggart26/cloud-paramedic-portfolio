# CloudMed — Cloud Computing Guide for Paramedics

A modern, responsive educational site about cloud computing for emergency and healthcare teams. It explains core concepts, service and deployment models, providers and regions, security and compliance, resilience, and cost optimization in Turkish with English cloud terminology.

## Live Site

https://flynntaggart26.github.io/cloud-paramedic-portfolio/

## Features

- Modern responsive UI with smooth animated transitions
- Cloud fundamentals based on the NIST cloud model
- Service models: IaaS, PaaS, SaaS, FaaS, DBaaS, DaaS
- Deployment models: public, private, hybrid, multi-cloud
- Provider and region awareness for data residency and latency
- Security, compliance, resilience, backup, and disaster recovery guidance
- Cost optimization and FinOps basics
- Glossary and trusted learning resources

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.
